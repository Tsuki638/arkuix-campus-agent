# 模型选择与默认配置

2026-11-17：应用只使用真实云端模型，默认 DeepSeek。模型设置使用“服务商 → 模型”两个下拉框，只保留一个“使用此模型”按钮；选择自定义接口后才显示地址和型号输入框。

## 预设接口

| 服务商 | 模型 ID | 完整 Chat Completions 地址 |
| --- | --- | --- |
| DeepSeek（默认） | `deepseek-flash`、`deepseek-v4-pro` | `https://api.deepseek.com/chat/completions` |
| 通义千问 | `qwen3.8-flash`、`qwen3.8-max` | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| Kimi | `kimi-k3.1-pro`、`kimi-k3.1-pro-highspeed` | `https://api.moonshot.cn/v1/chat/completions` |
| 智谱 GLM | `glm-5.3` | `https://open.bigmodel.cn/api/paas/v4/chat/completions` |
| OpenAI | `gpt-6-luna` | `https://api.openai.com/v1/chat/completions` |

配置集中在 `frontend/arkuix/entry/src/main/ets/services/model/ModelPresets.ts`。DeepSeek 的默认型号由 `DeepSeekConfig.ts` 管理。千问预设使用北京地域兼容域名；其他地域、业务空间专属域名及未列出的型号使用自定义接口。实际模型可用性取决于服务商账号权限、余额和网络。

预设按当日官方文档核对：[DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/)、[千问](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)、[Kimi](https://platform.kimi.com/docs/guide/kimi-k3-1-pro-quickstart)、[GLM](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3)、[GPT 6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)。未加入要求 Responses API 才能调用工具的型号，以保持现有 Agent 功能完整。

## 本机默认 DeepSeek

在项目根目录的 `.env.local` 中设置 `DEEPSEEK_API_KEY`，可选 `DEEPSEEK_MODEL`；不在命令参数、日志或聊天记录中提供密钥。执行：

```powershell
npm.cmd run prepare:model
```

脚本生成被 Git 忽略的 `frontend/arkuix/entry/src/main/resources/rawfile/local.model.json`。应用启动读取该配置并直接连接 DeepSeek；设置页的密钥输入框留空仍可沿用默认密钥。通过 `scripts/build-native.ps1` 构建时会自动运行准备脚本；直接从 DevEco 构建时，在第一次运行或更换本机密钥后先执行上述命令。

本机构建会将默认密钥打包进安装包，安装包应按含凭据的本机产物管理。公开分发应使用服务端代理，或不注入默认密钥、由每位使用者提供自己的凭据。

切换服务商会清空密钥输入框，默认密钥只绑定原 DeepSeek 完整地址，其他服务需要自己的 API Key。临时输入的密钥仅驻留当前运行，不写入历史；重启后恢复本机默认 DeepSeek。没有默认密钥的构建会打开模型设置，历史和计划仍可查看，不返回模拟答复。

## 协议与离线功能

- DeepSeek 显式关闭思考，保持已有工具协议；千问通过 `enable_thinking: false` 使用非思考模式。
- Kimi K3.1 Pro 和 GLM 5.3 保持思考开启，使用 `reasoning_effort: low`。工具往返保留 `reasoning_content`，按接口与型号绑定，切换模型不会将原推理内容传给新服务。
- GPT 6 Luna 使用 `reasoning_effort: none`，满足其 Chat Completions 工具调用要求。
- 移除应用的模拟模型、切回离线按钮、固定格式提示和 `npm run demo` 演示命令。自动化测试替身放在 `frontend/tests/support/`，不进入应用安装包。
