## 2. 你来做 ①：下载并安装 DevEco Studio（需华为账号）

1. 浏览器打开华为开发者联盟下载页（**先登录你的华为账号**）：
   - <https://developer.huawei.com/consumer/cn/deveco-studio/> →「下载」进入下载中心
   - 或 <https://developer.harmonyos.com/cn/develop/deveco-studio>
2. 选 **Windows (64-bit)**、与项目配套的版本。项目用的是 **HarmonyOS 6.1.1 / API 24**、
   ArkUI-X SDK 6.1.1.111；队友验证过的 IDE 是 **DevEco Studio 6.1.1.418**。请优先选
   6.1.1 Release 系列（官方 6.1.1.300 及补丁版），**不要选 26.0.0 等更高大版本**，
   避免与 API 24 工程和队友模板不配套。
3. 下载页会提供 SHA-256 完整性校验值，下载后核对一次。把安装包放到
   `E:\huawei-downloads\`（E 盘剩余空间建议 ≥ 100 GB）。
4. 双击 `deveco-studio-xxxx.exe` 安装，**安装路径改到 `E:\DevEcoStudio`**，勾选创建桌面快捷方式，
   一路下一步。首次启动若弹「Import DevEco Studio Settings」，选 **Do not import settings**。
5. 首次启动向导会安装 Node.js、ohpm、HarmonyOS SDK。按官方说明，**6.1.1 起 HarmonyOS SDK 已内嵌在
   IDE 的 `sdk/` 目录，不需要单独下载**；确认勾选了 **API 24 / 6.1.1** 对应的 SDK 与 Toolchains，
   路径保持默认 `E:\DevEcoStudio\sdk`。

> 如果下载中心提示需要**实名认证**，认证审核可能要 1–3 个工作日，这是全流程里唯一可能卡时间的
> 一步，建议今天先提交。下载中心页面是动态渲染的，没有可直接 curl 的匿名直链，所以我无法替你
> 完成这一步。

## 3. 你来做 ②：拿 ArkUI-X SDK 和 ACE Tools（需华为账号）

ACE Tools 随 ArkUI-X SDK 发布，**不要去 npm 装同名包**。两条路径任选：

- **推荐**：DevEco Studio → `File > Settings`（macOS 为 Preferences）→ `SDK` / `ArkUI-X` 页签，
  勾选与 API 24 配套的 **ArkUI-X SDK 6.1.1 / API 24** 下载。装完后 ACE 在
  `<ArkUI-X SDK>\24\arkui-x\toolchains\bin\ace.cmd`。
- 若 IDE 里没有该页签：回下载中心找 **ArkUI-X SDK** 独立包，解压到 `E:\ArkUI-X\`。

记下这两个路径，后面配置要用：

```text
E:\DevEcoStudio\sdk                         # HarmonyOS SDK（或 IDE 内实际显示路径）
E:\ArkUI-X\24\arkui-x\toolchains\bin\ace.cmd # ACE Tools（按实际解压层级调整）
```

队友记录的 ACE 自检命令在 `%APPDATA%\.aceconfig` 里保存配置；本机没有，需要重新执行一次
`ace config`（第 4 节由我来做）。

## 4. 我来做：环境登记与检查（你装完后告诉我路径即可）

我会按官方 `ace config` 把下列路径写入配置，然后跑 `ace check -v`，把必做项补齐：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-21.0.12'
$env:ANDROID_SDK_ROOT = 'E:\arkui-x-toolchain\android-sdk'
$env:ANDROID_HOME     = 'E:\arkui-x-toolchain\android-sdk'
$env:DEVECO_SDK_HOME  = 'E:\DevEcoStudio\sdk'
# ACE 路径加入当前终端 PATH（不改写系统环境变量）
$env:PATH = 'E:\ArkUI-X\24\arkui-x\toolchains\bin;' + $env:PATH

ace config --harmonyos-sdk "E:\DevEcoStudio\sdk" `
           --arkui-x-sdk  "E:\ArkUI-X\24" `
           --android-sdk  "E:\arkui-x-toolchain\android-sdk" `
           --java-sdk     "C:\Program Files\Java\jdk-21.0.12" `
           --nodejs-dir   "E:\DevEcoStudio\tools\node"
ace check -v
```

> `ace config` 的具体参数名以所装 SDK 的 `ace config --help` 为准；iOS 相关缺项不阻塞鸿蒙/Android。
> 检查通过后，仓库里已有官方工程壳（`app/build-profile.json5`、`.arkui-x/android`），
> **不需要**再跑 `initialize-arkuix.ps1` 重新生成，否则会覆盖队友整合的共享源码。

## 5. 你来做 ③：真机准备与调试签名（需华为账号）

### 5.1 鸿蒙真机

1. 确认系统版本：设置 → 关于本机，查看 HarmonyOS 版本 / API 版本。工程目标为 **API 24**，
   系统过低会装不上；把实际版本记下来（#5 要求登记设备与系统版本）。
2. 开启开发者选项：设置 → 关于本机 → 连续点击「版本号」约 7 次，按提示输入锁屏密码。
3. 开发者选项里打开 **USB 调试**（部分版本叫「开发者模式 / USB 调试」），连接电脑后
   在手机上点「允许 USB 调试」并勾选「始终允许」。
4. 用 USB 数据线连接（必须是数据线，不能只充电），电脑上验证：

```powershell
& 'E:\DevEcoStudio\sdk\default\openharmony\toolchains\hdc.exe' list targets
# 或（ACE 装好后）
ace devices
```

   看到设备 UDID 才算连通；`[Empty]` 说明驱动/授权没过，换线或重新授权。

### 5.2 自动签名（关键，必须账号）

DevEco Studio 打开仓库的 **`app/`** 目录，等待 Sync 完成，然后：

- `File > Project Structure > Project > Signing Configs`（不同版本菜单名略有差异）
- 勾选 **Automatically generate signature**（自动生成签名），按提示**登录你的华为账号**
- 首次使用需要**实名认证**；IDE 会自动申请调试证书、注册设备 UDID、生成 profile，
  并在 `build-profile.json5` 写入签名配置

> 证书、私钥、`.p12`、`.p7b` 和本机个人路径**绝不提交仓库**（#11 明确要求）。
> 自动签名失败时，检查：账号是否实名、设备是否已连上并能被 hdc 识别、手机是否联网、
> 包名 `com.example.campusagent` 是否与已有 profile 冲突。

### 5.3 Android 设备（不需要华为账号）

- 手机开启开发者选项 + USB 调试，或先用一个 Android 模拟器；
- `E:\arkui-x-toolchain\android-sdk\platform-tools\adb.exe devices` 看到设备即可；
- Android 侧用本机 debug 签名，不需要华为账号。

## 6. 构建与安装（第 4 节通过后我来做）

在仓库根目录（或工作副本 `E:\arkuix-campus-agent-C`）执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-native.ps1 -Platform HarmonyOS
powershell -ExecutionPolicy Bypass -File .\scripts\build-native.ps1 -Platform Android
```

脚本在 `app/` 里调用官方命令 `ace build hap --debug` / `ace build apk --debug`，并要求产物存在：

| 平台 | 产物目录 | 产物 |
| --- | --- | --- |
| 鸿蒙 | `app\entry\build\` | `*.hap` |
| Android | `app\.arkui-x\android\app\build\` | `*.apk` |

安装运行可用 DevEco 的 Run 按钮，或命令行：

```powershell
cd app
ace devices
ace run                       # 编译并在已连接设备上运行
# 或手动安装
& 'E:\DevEcoStudio\sdk\default\openharmony\toolchains\hdc.exe' -t <UDID> install <hap路径>
& 'E:\arkui-x-toolchain\android-sdk\platform-tools\adb.exe' install -r <apk路径>
```

**已知风险**：`app/.arkui-x/android/app/libs` 为空，Android 构建需要 ACE 先生成 ArkUI-X 运行时
库与 ArkTS 产物；若 `ace build apk` 报缺库，按 ACE 输出执行 `ace build` 的前置步骤再重试，
并把日志贴给我，我按报错定位。#5 要求把命令、日志、产物路径和源码提交一起记录。

## 7. 装好之后按什么顺序验收

先平台后业务，避免把环境问题误判成功能问题：

1. **#5**：两端都能安装并启动，登记设备/系统/SDK 版本与构建日志。
2. **#6**：按[C模块-设备验收与失败处理](C模块-设备验收与失败处理.md)第四节，两端各跑一遍
   真实文本对话、第二轮上下文、工具闭环，以及断网 / 无效密钥 / 超时三类失败反馈。
3. **#7**：两端各跑一遍「多轮 → 彻底退出 → 重开 → 回看 → 删除 → 再重启」，并验证损坏文件保护。
4. 之后才是 B 的 #8 页面、D 的 #9 语音、A 的 #10 Agent 演示，最后 #11 汇总材料。
   语音 ASR 必须真机（模拟器不支持 `speechRecognizer`）。

## 8. 常见坑

| 现象 | 处理 |
| --- | --- |
| `ace` 不在 PATH | 只给当前终端加 `<ArkUI-X>\24\arkui-x\toolchains\bin`，别改系统 PATH |
| `ace check -v` 缺 iOS 项 | 不影响鸿蒙/Android，忽略 |
| `hdc list targets` 为 `[Empty]` | 换数据线、重新点「允许 USB 调试」、确认驱动 |
| 真机装 HAP 报签名错误 | 重做自动签名，确认设备 UDID 已注册、账号已实名 |
| 装不上提示版本不兼容 | 核对设备 API 是否 ≥ 24，必要时调整 `compileSdkVersion` 并由平台负责人统一记录 |
| Android 构建缺 `libs` | 先让 ACE 生成运行时库，勿手动塞第三方包 |
| 应用内联网失败 | 检查 `module.json5` 的 `ohos.permission.INTERNET` 与 AndroidManifest 的 `INTERNET` 权限 |
| 密钥泄露风险 | 密钥只在应用运行时设置页输入，不写 `.env.local` 之外的文件、不进截图与日志 |
