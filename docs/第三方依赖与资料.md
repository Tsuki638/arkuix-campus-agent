# 第三方依赖与资料

## 当前使用与计划使用

| 项目 | 用途 | 来源/许可说明 | 当前状态 |
| --- | --- | --- | --- |
| ArkUI-X / ACE Tools | 共享 UI/业务跨端构建与平台宿主 | [官方项目](https://github.com/arkui-x)、[CLI](https://github.com/arkui-x/cli)，使用安装版本附带许可 | 未在当前机器完成配置 |
| DevEco Studio / HarmonyOS SDK | 鸿蒙工程、编译、调试和签名 | [华为官方 DevEco](https://developer.huawei.com/consumer/cn/deveco-studio/)，遵循下载许可 | D 配置并登记版本 |
| Android SDK / 构建工具 / JDK | Android 宿主构建与调试 | 各自官方分发渠道，按最终安装版本登记 | D 配置并登记版本 |
| `@ohos.net.http` | 共享 HTTP 适配器 | [ArkUI-X 官方 API 文档](https://github.com/arkui-x/docs/blob/master/zh-cn/application-dev/reference/apis/js-apis-http.md) | 已写适配源码，未设备验证 |
| `@ohos.file.fs` | 两端应用沙箱中的会话文件 | [ArkUI-X 官方 API 文档](https://github.com/arkui-x/docs/blob/master/zh-cn/application-dev/reference/apis/js-apis-file-fs.md) | 已写适配源码，未设备验证 |
| 鸿蒙 ASR/TTS Kit | 语音识别与播报 | D 按最终选用的华为官方 Kit 补充名称、SDK 版本、能力限制和条款 | 尚未选定或实现 |
| 云端模型服务 | 真实多轮对话与工具调用 | C 补充厂商、模型名、API 文档及服务条款，禁止登记真实密钥 | 尚未选定或调用 |
| Node.js 内置模块 | 本地开发演示与行为检查 | [Node.js 官方](https://nodejs.org/)，不作为移动端运行依赖 | 已使用，无外部 npm 包 |

本框架的业务代码未拷贝第三方示例实现；官方原生模板将在团队本机运行 `ace create` 时生成。生成后应保留模板中的许可证和来源信息，并按实际依赖补充本表。

## 已核对的官方参考资料

- [ArkUI-X 应用工程结构](https://github.com/arkui-x/docs/blob/master/zh-cn/application-dev/quick-start/package-structure-guide.md)：共享模块和 `.arkui-x` 平台宿主的组织。
- [ACE Tools 快速指南](https://github.com/arkui-x/docs/blob/master/zh-cn/application-dev/quick-start/start-with-ace-tools.md)：环境准备、创建与运行。
- [ACE Tools 命令](https://github.com/arkui-x/cli/blob/master/README.md)：`ace create`、`ace check`、`ace build hap/apk`、`ace run`。
- [ArkUI-X API 跨平台支持列表](https://github.com/arkui-x/docs/blob/master/zh-cn/application-dev/reference/apis/README.md)：按团队 SDK 版本核对系统能力。
- [Model Studio Function Calling](https://www.alibabacloud.com/help/en/model-studio/qwen-function-calling)：通用工具声明、调用及结果 ID 配对的参考；并未固定要求使用该厂商。

参考资料用于确定框架设计和接入步骤；实际兼容性以团队所选 SDK、模型及真机测试结果为准。
