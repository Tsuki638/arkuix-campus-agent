# 电脑与平板适配

2026-11-17 将共享 ArkUI 工程从手机兼容运行扩展为手机、平板和鸿蒙电脑共用的响应式工作台。保留现有对话、计划、日程和模型入口，适配不增加功能按钮。

## 设备与窗口

`frontend/arkuix/entry/src/main/module.json5` 声明 `phone`、`tablet`、`2in1`，由同一份 UI 和业务逻辑运行。鸿蒙电脑按 `2in1` 设备支持声明运行，不再只依赖手机兼容窗口。

`EntryAbility` 支持 `fullscreen`、`split` 和 `floating`。自由窗口默认大小为 1120 × 760 vp，最小尺寸为 320 × 480 vp，没有设置手机式的固定宽高比或窗口最大宽度限制。实际窗口仍受系统可用区域和用户窗口操作影响。

方向为 `auto_rotation_restricted`，平板横竖屏旋转遵循系统旋转开关。`pages/Index.ets` 使用 `KeyboardAvoidMode.RESIZE`，软键盘弹出时压缩可用内容区。

官方依据：[电脑适配](https://developer.huawei.com/consumer/cn/doc/doccenter-multi-device/bpta-pc-guide/)、[多设备窗口模式](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-multi-device-window-mode/)。SDK 字段及键盘避让接口另按本机 API 24 声明核对并编译验证。

## 页面规则

尺寸按应用根内容区的实际 vp 计算，窗口缩放、平板旋转和分屏使用同一套规则。阈值集中在 `ui/WorkspaceLayout.ts`。

| 实际可用尺寸 | 页面行为 |
| --- | --- |
| 宽度小于 600 vp | 抽屉导航，首页两个入口纵向排列，左右各留 16 vp |
| 宽度 600–899 vp | 抽屉导航，首页两个入口横向排列，左右各留 24 vp |
| 宽度达到 900 vp | 264 vp 常驻侧栏，可手动收起；主内容左右各留 32 vp |
| 高度小于 600 vp | 压缩顶部、侧栏及输入区留白，欢迎页隐藏装饰头像，保留滚动区域 |

对话及输入区保持最多 800 vp 的阅读宽度，外层工作区占满窗口。模型设置、计划及日程页继续保持居中、可滚动的内容布局。窗口尺寸改变只更新布局状态，不重建业务运行时，也不主动清空输入、对话或模型配置。

## 构建与部署

新配置已经完成 API 24 ArkTS 编译及未签名 HAP 打包，产物：

```text
frontend/arkuix/entry/build/default/outputs/default/entry-default-unsigned.hap
```

更新设备和窗口声明需要重新构建并覆盖安装。仅重新启动模拟器或点击桌面旧图标，不会更新已安装的包。DevEco 打开 `frontend/arkuix/`，选择 `entry` 和在线目标，使用完整 Run；保留应用数据以保留已有对话和计划。
