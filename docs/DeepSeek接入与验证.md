# DeepSeek 接入与验证

2026-11-11 已使用 DeepSeek 官方 API 完成真实联网验证。请求使用应用实际的 `CompatibleModelClient`、`AgentEngine`、工具注册表和数据仓库，Node 只替换设备 HTTP 与存储端口。本次结果不包含设备端 HTTP、文件读写、语音和 Android 验收。

## 当前配置

| 项目 | 配置 |
| --- | --- |
| 完整接口 | `https://api.deepseek.com/chat/completions` |
| 模型 ID | `deepseek-flash` |
| 思考模式 | `thinking: { type: 'disabled' }` |
| 单次最大输出 | `max_tokens: 2048` |
| 密钥 | 本机 `.env.local` 中的 `DEEPSEEK_API_KEY`；应用内通过密码输入框提供 |

默认配置集中在 `app/entry/src/main/ets/services/model/DeepSeekConfig.ts`。根据[官方接入文档](https://api-docs.deepseek.com/)选择当前模型，并按[官方工具调用示例](https://api-docs.deepseek.com/guides/tool_calls/)显式使用非思考模式。当前适配器尚未保存和回传思考模式所需的推理字段，不能直接启用该模式。

供应商参数只对官方 `api.deepseek.com` 主机启用，其他兼容接口沿用通用请求格式。第三方中转需按其实际协议另行验证。

## 本机复测

本机已建立 `.env.local`。其他开发者可复制 `.env.example` 为 `.env.local`，自行填写密钥。文件格式如下，等号右侧填实际密钥：

```dotenv
DEEPSEEK_API_KEY=
```

在项目根目录执行：

```powershell
npm.cmd run verify:deepseek
```

需要能访问官方接口的网络；该命令会产生实际 API 用量。Node 版本要求与项目一致。可选 `DEEPSEEK_MODEL` 仅覆盖本机验证模型，不改变应用内默认值。

该命令严格使用 DeepSeek 专用密钥变量，不读取其他供应商的 `MODEL_API_KEY`。密钥只进入请求端口的 Bearer 鉴权头，不进入模型消息、会话或计划。`.env.local` 已被 Git 忽略，也不会被打包进 HAP。没有密钥时命令退出码为 2，验证失败时为 1，通过时为 0。

每次实际执行会更新被 Git 忽略的 `.generated/deepseek-verification.json`，记录通过状态、HTTP 状态、消息数量、用量、最终答复与检查项；报告不保存密钥、鉴权头或完整请求报文。

## 本次验证结果

2026-11-11 的真实验证共 3 次请求，HTTP 状态全部为 200：

1. 第一轮要求“调用 create_study_plan 工具，为复习高数制定 3 天的计划”，真实模型返回工具调用，应用执行工具并保存计划。
2. 应用将执行结果回传，真实模型返回计划创建结果；检查仓库恰好有一份计划、包含 3 天任务。
3. 第二轮询问此前计划的科目和天数，真实模型回答“刚刚保存的计划针对高数（高等数学）复习，持续 3 天”，没有重复调用工具。

另检查会话与计划可以从仓库序列化字符串恢复，且保存内容不含密钥。此处使用内存端口重新装载 JSON，不等于设备退出重启验收。

`npm.cmd run check` 的 35 项测试通过；新增回归覆盖 DeepSeek 的工具往返、第二轮上下文和通用接口的供应商参数隔离。API 24 原生 ArkTS 编译和未签名 HAP 打包通过；构建保留已有平台语音与文件 API 警告。

## 应用内使用

1. 用 DevEco 打开项目的 `app/`，运行更新后的共享页面。
2. 手机端先打开左上角侧栏，进入“模型设置”。
3. 点击“填入 DeepSeek 官方配置”，自动填入接口和模型；输入 API Key，点击“应用云端配置”。
4. 发送“请为复习高数制定 3 天计划”，查看模型回复与“学习计划”中的任务，再追问此前计划的科目和天数。

`.env.local` 仅供电脑上的 Node 验证命令读取，应用仍通过设置页接收运行时密钥；应用重启后需重新配置。切换到官方配置时会清空输入框中的旧密钥，避免切换服务商时沿用错误凭据。

本次 HDC 未发现连接的设备或模拟器，尚未完成应用内真实联网与设备文件恢复验证。设备就绪后，需补齐上述操作、断网反馈、退出重启回看与语音闭环。

当前工具仍生成基础按天模板任务。接入真实模型后，具体内容规划、读取和修改已有计划、系统日历写入等功能仍按[真实 Agent 升级路线](真实Agent升级路线.md)逐项实现。
