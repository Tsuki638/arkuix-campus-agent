# 学习工作台界面

2026-11-17 精简共享 ArkUI 学习工作台，突出对话、学习计划与日程确认，减少重复入口和无效操作。应用使用现有 ArkUI-X 原生工程，鸿蒙与 Android 共用组件、Agent 和本地仓库。

## 布局与视觉

- 采用暖白内容区、浅灰绿侧栏、深色主要按钮，完成状态使用低饱和绿色；统一边框、留白和文字层级，去掉输入区阴影与装饰性文案。
- 可用宽度达到 900 vp 时显示 264 vp 的侧边栏，可手动收起。小于 900 vp 时通过左上角按钮打开导航抽屉；点击遮罩或按系统返回键关闭。
- 工程声明手机、平板和电脑设备支持，电脑使用默认 1120 × 760 vp 的自由窗口。600–899 vp 的中等窗口已可横向显示首页入口；小于 600 vp 时纵向排列。可用高度小于 600 vp 时压缩装饰和留白，键盘弹出时调整内容区高度。配置与验证见[电脑与平板适配](电脑与平板适配.md)。
- 对话正文和输入区最大宽度为 800 vp。首页与长消息区域可滚动，输入面板位于聊天区底部。
- 手机、平板与电脑使用同一份聊天组件、回复排版和模型设置。消息滚动区在正文两侧各延伸 12 vp，条目内部补齐相同留白，使右侧滚动条向外移动 12 vp，正文和输入框保持原有对齐及阅读宽度；窄窗口右侧仍保留安全间距。
- 配色集中在 `frontend/arkuix/entry/src/main/ets/ui/WorkspaceTheme.ts`；图标由原生 Path 绘制，通过 Shape 的像素视口映射到 vp 尺寸，不依赖额外字体、网络图片或 WebView。
- 首页、侧栏与助手头像使用浅绿色圆形幼苗标识；首页只保留考研准备和就业探索，窄屏纵向排列、宽屏横向排列。入口不使用固定高度截断说明。
- 聊天顶部仅保留导航、标题、模型状态和按需显示的对话菜单；新建对话与删除不再各占一个按钮。删除仍需确认，其他页面使用左侧返回按钮回到对话。

## 已接通的操作

| 区域 | 行为 |
| --- | --- |
| 导航与历史 | 新建对话、切换历史、进入计划、日程与模型设置；超过五段有效对话时显示搜索；空对话不占历史列表，当前已是空对话时复用，保留输入草稿 |
| 首页入口 | 考研准备、就业探索；点击后填入输入框，由用户发送，也可直接输入其他目标 |
| 模型相关提示 | 统一填入自然语言访谈提示；启动默认使用本机 DeepSeek，无离线入口 |
| 输入面板 | 多行输入、发送；设备支持时显示语音输入，识别或播报时原位切换为停止；硬件键盘 Enter 发送、Shift + Enter 换行；软键盘保留换行 |
| 对话结果 | 用户消息靠右，助手回复按标题、正文、加粗重点和列表分层排版；工具结果可展开，成功的学习计划结果可进入计划页 |
| 学习计划 | 用一行文字汇总计划与完成数；保留每份计划的进度条、完成/撤销和准备日程操作；读取失败时提供重试 |
| 模型设置 | 统一从侧栏进入；服务商和模型下拉选择，预设五家官方 API；DeepSeek 沿用默认密钥，其他服务需填写自己的密钥；只保留“使用此模型”按钮 |
| 日程预览 | 保留逐项编辑、确认写入、取消与失败重试；空态只显示安排日程入口，有记录或读取失败时才提供刷新/重试 |
| 返回与异常 | 系统返回键先关闭抽屉、再从计划或设置返回对话；初始化失败提供重新加载入口 |

搜索只在已有本地会话中进行。手动输入的密钥仅驻留本次运行，离开设置时清空输入框。默认 DeepSeek 从本机生成且被 Git 忽略的配置读取，详见[模型选择与默认配置](模型选择与默认配置.md)。页面继续使用已有 Agent、计划和日历接口。

## 回复排版

- `ReplyFormatting.ts` 解析常用 Markdown 子集，`FormattedReply.ets` 使用原生 `Text`/`Span` 展示，不依赖网页组件或额外网络请求。
- `#`、`##`、`###` 标题分别使用 22、20、18 的字号和加粗字重；更深层级沿用 18。正文为 15、行高 26，标题前后留白有明确区别。
- 支持行内加粗、斜体、行内代码、有序/无序列表与缩进、引用、代码围栏和分隔线。列表保持模型给出的编号，换行后的文字与条目内容对齐。代码使用等宽字体，窄窗口自动换行。
- 历史回复中单独一行且不超过 80 字的 `**小节标题**` 或 `__小节标题__` 也按小标题展示。同一段内的多个加粗片段仍作为正文。
- 只改变显示方式，不改写会话里保存的原始内容。未闭合的强调标记保留原文；代码中的格式符号不会再次解析。HTML 按普通文字显示。此组件不是完整 Markdown 引擎，暂不提供表格、图片和链接跳转。
- 系统提示要求较长的新回复使用简短标题、适量重点加粗和列表；简短回复不强制分段。界面没有新增格式开关或工具栏。

## 设备复核步骤

1. 在 DevEco Studio 打开 `frontend/arkuix/`，同步并运行 `entry`。新会话应显示两个场景入口和底部输入面板；输入区没有模型设置按钮，语音不可用时没有麦克风按钮。
2. 点击“考研准备”，确认填入自然语言访谈提示；发送并继续交流。发送“请制定三天高数复习计划”验证模型调用工具，展开结果并进入学习计划。
3. 标记一项任务完成，检查进度条和完成数；再次点击撤销，退出重启检查本地记录。
4. 打开导航，切换历史、新建对话；当前已是空对话时再次新建应保留输入草稿，且空对话不出现在历史列表。超过五段有效对话时验证搜索；进入聊天右上角菜单删除当前对话，先取消一次，再确认一次。
5. 从侧栏进入模型设置，检查五家服务商与型号切换、接口自动填充、默认 DeepSeek 留空沿用密钥、自定义输入、缺少密钥时禁用按钮。切换服务商清空密钥输入；全程不显示离线入口。其他服务商使用有效密钥另行联网验证。
6. 检查窄屏、宽屏、横竖屏切换、大字体、软键盘弹出、长消息与系统返回键。设备支持语音时检查语音输入与停止。
7. 打开旧的考研准备回复，确认 `**一、时间条件**` 一类标记已变为加粗小标题，编号列表换行对齐；新回复检查三级标题、行内加粗及长段落滚动，内容不会被固定高度截断。
