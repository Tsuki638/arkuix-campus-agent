# 学习工作台界面

2026-11-11 将共享 ArkUI 界面调整为 Codex 风格的学习工作台。应用仍使用现有 ArkUI-X 原生工程，鸿蒙与 Android 共用组件、Agent 和本地仓库。

## 布局与视觉

- 采用暖白内容区、浅灰侧栏、深色主要按钮，学习任务完成状态使用低饱和绿色。
- 可用宽度达到 900 vp 时显示 264 vp 的侧边栏，可手动收起。小于 900 vp 时通过左上角按钮打开导航抽屉；点击遮罩或按系统返回键关闭。
- 对话正文和输入区最大宽度为 800 vp。首页与长消息区域可滚动，输入面板位于聊天区底部。
- 配色集中在 `app/entry/src/main/ets/ui/WorkspaceTheme.ts`；图标由原生 Path 绘制，通过 Shape 的像素视口映射到 vp 尺寸，不依赖额外字体、网络图片或 WebView。
- 首页、侧栏与助手头像使用浅绿色圆形幼苗标识；首页入口使用浅色图标底座、圆角边框与横向标题，减少手机上的视觉负担。

## 已接通的操作

| 区域 | 行为 |
| --- | --- |
| 导航与历史 | 新建对话、按标题搜索、切换历史、进入计划与模型设置；删除当前对话前显示确认 |
| 首页入口 | 考研准备、就业探索、制定计划和短期挑战；点击后填入输入框，由用户发送 |
| 模型相关提示 | 默认离线示例填入合法的“目标\|天数”；配置云端模型后填入自然语言访谈提示 |
| 输入面板 | 多行输入、发送、模型设置入口、语音输入与停止；硬件键盘 Enter 发送、Shift + Enter 换行；软键盘保留换行 |
| 对话结果 | 用户消息靠右，助手正文显示在内容区；工具结果可展开，成功的学习计划结果可进入计划页 |
| 学习计划 | 汇总计划数、任务数与完成数；每份计划有进度条，点击任务可完成或撤销 |
| 模型设置 | 接口地址、模型名称、密码式密钥输入、校验反馈、应用云端配置或切回离线示例 |
| 返回与异常 | 系统返回键先关闭抽屉、再从计划或设置返回对话；初始化失败提供重新加载入口 |

搜索只在已有本地会话中进行。密钥沿用原有运行时配置方式，不持久化，离开设置时清空输入中的密钥。新界面没有新增方向访谈算法、日历写入或模型能力。

## 设备复核步骤

1. 在 DevEco Studio 打开 `app/`，同步并运行 `entry`。新会话应显示欢迎页、四个场景入口和底部输入面板。
2. 点击“制定计划”，确认输入框出现 `复习高数|3`，点击发送；展开工具结果并进入学习计划。
3. 标记一项任务完成，检查进度条和完成数；再次点击撤销，退出重启检查本地记录。
4. 打开导航，搜索已有对话、切换历史、新建对话；删除一段对话时先取消一次，再确认一次。
5. 进入模型设置，检查无效配置提示、密钥隐藏和离开设置时清空密钥输入。真实模型连通性使用有效配置另行联调。
6. 检查窄屏、宽屏、横竖屏切换、大字体、软键盘弹出、长消息与系统返回键。设备支持语音时检查语音输入与停止。
