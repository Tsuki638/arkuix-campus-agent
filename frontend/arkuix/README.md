# ArkUI-X 应用源码

原 `app/` 已整体迁移到本目录。Java 后端位于仓库根目录 `backend/`；新增 HTTP 适配入口见[前端工程说明](../README.md)。当前原有端内 Agent、模型和存储仍继续运行，尚未由 Java 业务替代。

`entry/src/main/ets/` 是鸿蒙与 Android 共享的业务及 UI 源码，按 `agent/ui/services/platform` 四个部分分工，公共边界在 `contracts/`。

鸿蒙手机、平板和电脑统一使用这里的页面、回复排版、模型设置及 Agent；界面改动统一应用到三端，按实际窗口宽高调整布局。模块声明 `phone`、`tablet`、`2in1`，三端使用同一份 HAP 更新；各设备已安装的旧版本需要覆盖安装最新包才能生效。

此目录已补齐 **API 24 官方 ArkUI-X 工程配置、Ability、资源与 Android 宿主源码**。用 DevEco 打开本目录，完成同步与本机签名后运行 `entry`，默认进入聊天页。整合工程的未签名 HAP 构建已通过。

当前版本包含模型选择、基础学习计划保存与打卡，以及语音接入。在根目录执行 `npm.cmd run prepare:model` 后，默认使用本机 DeepSeek；发送“请制定三天高数复习计划”即可验证工具流程。其他服务在侧栏“模型设置”选择，应用没有离线模式。配置与验证边界见[模型选择与默认配置](../../docs/模型选择与默认配置.md)和[整合与联调](../../docs/整合与联调.md)。

具体步骤见 [构建与运行](../../docs/构建与运行.md)，分工见 [四人分工与里程碑](../../docs/四人分工与里程碑.md)。

语音负责人现在可以用 [语音开发与联调](../../docs/语音开发与联调.md) 中的独立工程先做模拟器测试：在根目录执行 `scripts/prepare-speech-demo.ps1`，用 DevEco 打开 `.generated/speech-demo/`。该工程使用本目录的共享源码，提供语音自测页与真实模型聊天入口；没有默认密钥时在模型设置中填写。
